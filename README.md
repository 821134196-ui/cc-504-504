# 食堂新食材封样盲评系统

选用新食材前对供应商试样进行**收样登记 → 封样库位 → 匿名盲评 → 回避 → 两人揭盲 → 结果复核**的闭环管理。
零第三方依赖，仅使用 Node.js 22 内置 `node:sqlite` 与原生 HTTP。

## 一条本地命令启动

```bash
npm start          # 默认 http://localhost:3000
PORT=8080 npm start
```

首次启动自动建库、写入演示数据（**自带一份封签破损样例 SP-2026-002**）、生成本地占位照片。

| 角色 | 账号 | 口令 |
|---|---|---|
| 管理员 | `admin` | `admin123` |
| 采购员 | `buyer` | `buyer123` |
| 评审人 | `r1` / `r2` / `r3` | `rev123` |

## 六项交付页面

| 页面 | 路径 | 能做什么 |
|---|---|---|
| 收样登记 | `/` | 登记品类/产地/到货温度/批次/封存编号；封签破损、到货超温、过期自动标记、留痕并发模拟通知 |
| 封样库位 | `/storage` | 分配库位、上传本地样品照片、上报封签破损、供应商撤样 |
| 盲评表 | `/review`（评审人） | 按样品编号展示，**不显示供应商**；感官评分（口感/规格 1–10）与实测烹调损耗分区填写 |
| 回避申请 | 盲评页内申请，管理员在 `/admin/recusals` 审批 | 批准后该评审人对此样品的评分入口关闭 |
| 揭盲 | `/reveal` | 当前登录人 + 第二授权人现场口令，**两人同时揭盲** |
| 结果复核 | `/results`、`/result/:id` | 揭盲后对照各评审人意见与供应商，提交选用意见 |
| 访问审计 | `/audit`（管理员） | 全部允许/拒绝访问留痕 |

## 业务规则（均有测试覆盖）

- **匿名隔离**：揭盲前评审人看不到供应商；主动探测身份返回 403 并写审计；揭盲后才公开。
- **采购员不能替评审人填分**：非评审人提交评分 403 并留痕，且不入库。
- **评分完整性**：口感/规格/烹调损耗任一漏填或越界都拒绝并写 `score_missing_items` 事件。
- **回避**：经批准的回避会拦截评分，单独记录 `score_blocked_recusal`。
- **两人揭盲，竞态安全**：`revelations.sample_id` 唯一 + `BEGIN IMMEDIATE` 串行化，
  并发请求只产生**一次**结果、一条通知；重复揭盲返回同一条既有结果。
- **一个封存编号只能关联一份当前样品**：部分唯一索引
  `ON samples(seal_no) WHERE is_current = 1`；破损/过期/撤样/揭盲后编号释放可复用。
- **异常全留痕**：封签破损、到货超温、样品过期、撤样、回避、漏项、揭盲、复核都进 `events`；
  所有越权/合规动作进 `audit_log`。

## 留痕与数据

- **SQLite**（`data/app.db`）：评分、揭盲、回避、复核、`events` 留痕、`audit_log` 访问审计、模拟通知记录。
- **本地照片**：`data/photos/`（收样页可上传图片，路径入库）。
- **模拟通知适配器**：`src/domain.js` 的 `createNotifier`，接口与真实短信/钉钉/邮件一致，目前落库 + 控制台输出。

## 测试

```bash
npm test
```

覆盖四类要求场景（15 个用例，领域层 + 真实 HTTP 并发）：

1. **匿名隔离** — 列表/详情/主动探测在揭盲前对评审人屏蔽供应商，揭盲后公开；
2. **揭盲竞态** — 领域层 20 个事务、HTTP 层 8 个独立会话并发揭盲，结果唯一；
3. **回避** — 申请→批准→评分拦截留痕全流程；
4. **评分完整性** — 采购员禁填、漏项/越界拒绝留痕、一人一样品仅评一次。

另含收样异常（破损/超温/过期）、封存编号唯一、撤样迁移、第二揭盲人口令校验、复核一次性等。

## 目录结构

```
src/db.js       SQLite schema（含封存编号部分唯一索引、揭盲唯一约束）
src/domain.js   全部业务规则、留痕、审计、通知适配器
src/seed.js     演示数据（含封签破损样例）
src/views.js    页面（白/炭灰/食材绿，无彩色评分暗示）
src/server.js   原生 HTTP：会话、鉴权、路由、照片上传
test/           node:test 领域层与 HTTP 端到端测试
```
